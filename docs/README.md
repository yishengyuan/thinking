## 🧵 一条贯穿职场三篇的主线

三篇职场反思其实是**同一个根**:

> **别当那个把冲突/诉求默默吞掉的中间人——把它显性化,并翻译成对方关心的语言。**

```mermaid
flowchart LR
    CORE[别默默吞<br/>把诉求显性化 + 翻译成对方的语言]
    CORE --> A[按角色沟通<br/>把'我做了什么'<br/>换成'对方关心什么']
    CORE --> B[优先级冲突<br/>把风险/容量置换<br/>显性交给有权的人]
    CORE --> C[该不该挑任务<br/>把成长诉求显性沟通<br/>翻译成团队需要]

    style CORE fill:#fff3e0,stroke:#fb8c00
```

- **按角色沟通**:把「我做了什么」换成「对方关心什么」。
- **优先级冲突**:把风险、容量置换显性化,交给有决策权的人拍板,并留痕、让结论回流。
- **该不该挑任务**:把成长诉求显性沟通,翻译成"团队的活有没有人好好干"。
