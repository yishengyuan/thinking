## 🧵 一条贯穿职场反思的主线

四篇职场反思其实是**同一个根**:

> **别当那个把冲突/诉求默默吞掉的中间人 —— 把它显性化,并翻译成对方关心的语言。**

```mermaid
flowchart LR
    CORE[别默默吞<br/>把诉求显性化 + 翻译成对方的语言]
    CORE --> A[按角色沟通<br/>'我做了什么'→'对方关心什么']
    CORE --> B[优先级冲突<br/>风险/容量置换显性交给有权的人]
    CORE --> C[该不该挑任务<br/>成长诉求显性沟通→翻译成团队需要]
    CORE --> D[非自己的bug怎么汇报<br/>客观根因显性化,但用事实而非指责]

    style CORE fill:#fff3e0,stroke:#fb8c00
```
